### How it is built

- **The UI is the app's.** `src/v2/ui.tsx` and `src/v2/pages.tsx` are frame-driven ports of
  `frontend/components/*` and `frontend/app/**`: same markup, inline styles, copy and states,
  including the fixes made alongside this video ("Not answered" scores, parallel-dial copy).
  Inter stands in for SF Pro; it is embedded in the bundle (`src/v2/inter-data.ts`) and the
  composition waits for it from inside a component. A module-level `delayRender()` does not
  survive here: `@remotion/media-utils` loads the CommonJS build of `remotion` next to the
  ESM one, and the second copy resets the pending-handle list, so the orphaned timeout
  aborts long renders (see `src/v2/fonts.ts`).
- **The cursor aims at real elements.** A keyframe names an element (`data-t="launch"`), and
  `src/v2/stage.tsx` measures where that element is in a frozen copy of the scene at the
  frame the pointer arrives — no hand-placed coordinates. Pages scroll to elements the same
  way (`planScroll`).
- **Every number comes from the backend.** `scripts/make_results_v2.py` writes each reference
  as the `structured_result` CALL-E returns for the Software Engineer template and scores it
  with `services/calle_service.py` — the same functions the webhook runs. James 9.52,
  Priya 8.25, Daniel 7.43 (policy-limited: unanswered questions are excluded, not averaged in)
  → Maria 8.4, *Yes*.
- **The call follows the real task prompt.** The agent's opening, the follow-up probe, the
  HR-policy response and the close are worded exactly as `build_reference_task()` instructs.
  The transcript shown in the report is the same text the viewer hears.

### Voices

All speech is **Kokoro-82M** (local, open-weight, Apache-2.0), generated by
`scripts/make_audio_v2.py` through `scripts/kokoro_tts.mjs`:

| Role | Voice | Predicted naturalness (UTMOS22) |
|------|-------|------|
| Narrator | `am_fenrir` | 4.50 |
| Alex, the CALL-E agent | `af_heart` | 4.52 |
| James (referee) | `am_puck` | 4.50 |
| Daniel (referee) | `am_michael` | 4.39 |

The cast was picked by scoring 47 candidate voices (Kokoro and Microsoft Edge neural) with the
UTMOS22 MOS predictor; the Edge voice used for the v1 narration scored 4.35. Every generated
line was then transcribed with Whisper (`openai/whisper-small.en`) and compared with the
script; lines the recogniser could not recover were reworded and regenerated. Referee lines
are band-limited like a phone line; the agent sounds like the platform side of the call.
Ringback, pickup, hang-up, clicks and key taps are synthesised with ffmpeg — no third-party
audio.

### What is real and what is re-created

- **Real:** the UI (design, copy, states), the CALL-E request the app sends, the scoring, the
  report and PDF layouts.
- **Re-created:** the phone calls. CALL-E's API returns transcripts and structured results but
  no call recordings, and no real referee was dialled for this video — the conversation is
  synthetic speech following the app's call script, with fixture data. If you mention the
  video in your submission text, say so.

### Rebuild

```bash
npm install
python scripts/make_audio_v2.py --preview          # voices + effects → public/v2/audio, src/v2/audio-manifest.json
..\backend\.venv\Scripts\python scripts/make_results_v2.py   # scores → src/v2/results.json
npm run render:v2                                   # → refcheck-ai-demo-v2.mp4
npm run stills:v2 -- 1462 2364 3983                 # review frames → out/stills/
```

Timing lives in `src/v2/timeline.ts` (segment lengths are fitted to the measured audio);
the spoken words live in `src/v2/script.json`.

## v1 (`RefCheckDemo`)

The first cut: the app's design system with a narrator over each scene, and the call shown as
a text transcript with the `client.calls.create(...)` → `call.completed` → `structured_result`
round trip. Narration is Microsoft Edge neural TTS (`en-US-AndrewMultilingualNeural`) from
`scripts/vo.py`. Re-render with `npm run render`.

The backend now implements exactly the CALL-E call that v1 shows on screen (`calle-ai` SDK,
`api.heycall-e.com`, `client.calls.create(task=…, result_schema=…)`).
